# Archived Contract Directory

This folder contains the **original, pre‑ontology contract files** from early versions of the Unified‑Model.  
These files are **no longer active** and have been superseded by the reorganized, ontology‑layered contract structure.

All current and future work should reference the updated contracts located in:

- `PHYSICS_SUBSTRATE_CORE/`
- `GEOMETRY_PREDICTION_WINDOWS/`
- `INTEROCEPTION_LOAD_AND_FAILURE/`
- `SEMANTIC_COGNITION_AND_LANGUAGE/`
- `SOCIAL_ENVIRONMENT_PRESSURE/`
- `TRANSFORMER_ANALOGS_AND_REASONING/`

Each updated contract includes:

- unified headers  
- expanded filenames  
- ontology layer assignment  
- upstream/downstream dependencies  
- cross‑contract references  
- canonical bootloader links  

These archived files remain here **for historical reference only** and should not be used for traversal, loading, or model interpretation.

For the active entry point, begin with:

**`PHYSICS_SUBSTRATE_CORE/minimal_core_physics.md`**

This is the canonical bootloader for both humans and AI models.
