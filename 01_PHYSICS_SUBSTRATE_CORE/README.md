# **PHYSICS_SUBSTRATE_CORE — Substrate Layer Overview**

This folder contains the **physics substrate** of the Unified‑Model. All higher‑level regulatory, cognitive, interoceptive, semantic, social, and transformer phenomena emerge from the primitives defined here.

This README is for **human readers**. AI models should begin with: `minimal_core_physics.md`

## **Purpose of This Layer**

The physics substrate defines the mechanical foundation of the regulatory architecture:

- **Pressure**
    
- **Amplitude**
    
- **Oscillation**
    
- **Gating**
    
- **Mechanical Coupling**
    
- **Phase Dynamics**
    

These primitives govern:

- autonomic state
    
- RSA amplitude
    
- HRV geometry
    
- prediction‑window width
    
- collapse modes
    
- cognitive flexibility
    

Every other folder in the repo builds on this layer.
