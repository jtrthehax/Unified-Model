## 2. Mechanical Engine (Core Loop)

The core loop of the system is:

> **Breathing mechanics → HRV transduction → autonomic gating → prediction‑window geometry**

### 2.1 Breathing Mechanics

- Inhale: diaphragm descends → intrathoracic pressure drops → venous return increases → heart rate accelerates.  
- Exhale: diaphragm ascends → intrathoracic pressure rises → baroreceptor stretch increases → vagal burst → heart rate slows.

Breathing is the pressure engine.

### 2.2 HRV Transduction

- Pressure changes deform baroreceptors.  
- Stretch‑activated ion channels convert mechanical force into electrical signals.  
- Vagal output modulates heart rate beat‑to‑beat.

HRV amplitude = diaphragm amplitude.  
HRV frequency = breathing frequency.

### 2.3 Autonomic Gating

- High amplitude + low frequency → parasympathetic mode.  
- Low amplitude + high frequency → sympathetic mode.

The NTS (Nucleus Tractus Solitarius) locks modes based on oscillation geometry, not abstract “stress.”

### 2.4 Prediction‑Window Geometry

- Wide amplitude → wide cognitive window (exploratory, flexible).  
- Collapsed amplitude → narrow window (defensive, rigid).  
- High‑frequency oscillation → unstable, jittered window.  
- Low‑frequency oscillation → stable, integrative window.

Cognition is bounded by this geometry.
